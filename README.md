# Cosserat-rod-shell-dynamics

Numerical data and simulation videos for Cosserat rod-shell dynamics.

The [dataset directory](Cosserat-rod-shell-dynamics/) contains 587 numerical
records and two MP4 recordings.

- [Data index](Cosserat-rod-shell-dynamics/DATA_INDEX.csv)
- [Video index](Cosserat-rod-shell-dynamics/VIDEO_INDEX.csv)
- [Record scope](Cosserat-rod-shell-dynamics/INFO.txt)
- [SHA-256 checksums](Cosserat-rod-shell-dynamics/CHECKSUMS.txt)

Saved numerical values and failure flags are retained. Incomplete convergence
and accuracy assessments remain incomplete. The recordings show historical
reduced and one-way structural simulations, not physical experiments.
